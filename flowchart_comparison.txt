  ◆ query 改写熔断路径（新功能）
    resolve_context_node → resolve_query(query, session_history) →
    LLM 消解指代 + 口语→专业改写 →
    BGE 余弦相似度对比 query vs resolved_query：
      ① 相似度 ≥ 0.2 → 保留改写结果
      ② 相似度 < 0.2 → 回退用户原话，防止 LLM 改写跑偏全链路

  ◆ _llm_fallback 降级路径（搜索全失败时）
    search_node 标记 search_all_failed=true →
    assess_node 检测 search_all_failed 且 findings 为空 →
    立即标记 _llm_fallback=true →
    route_assess 检测 _llm_fallback → 直接走 synthesize →
    synthesize 调用 LLM 直接回答（用自身知识）→
    report_node 检测到 sections 中有内容，直接输出

  ◆ 自动冲突裁决路径（assess 内部）
    assess_node 检测到 has_conflict=true →
    收集冲突方来源URL + 可信度评分 →
    使用已有 scraped_pages 原文 + LLM 事实核查 →
    ① 能裁决 → 自动消解，has_conflict=false
    ② 不能裁决 → has_conflict=true，触发 hitl_conflict HITL
